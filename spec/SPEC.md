# データ基盤ポータルサイト

Databricksを使った自動車関連のデータカタログ、データアプリ管理、データ分析のためのポータルサイト

## 環境
- Databricks
- AWS
- Python 3.11 (バックエンド)
- TypeScript (フロントエンド)
- React + Vite (フロントエンド)

## 扱うデータ
- 時系列データ: 走行軌跡、車両状態、故障状態が時系列で記録されたデータ。車両からアップロードされあらかじめ共通のカタログとして登録されているものとする。
- ドメイン別データ: 各ユーザーが取り組む業務ドメインで生成したデータ。実験データなど。データカタログに登録することで他のドメインやチームからも閲覧できる。

## 設計方針
Databricksのサービスを最大限活用すること。AWS Lambdaのように、インスタンスの常時起動を必要としないサーバーレスアーキテクチャとすること。
backstage.ioを使っても良い。

## ユーザーの役割
- システムアドミン: ポータル、Databricksを管理するユーザー。システム、アカウントレベル、メタストアレベルの権限を持つ。
- データオーナー: データカタログを作成したユーザー。カタログの閲覧申請の承認を行う。データ品質の管理責任を負う。カタログ内のスキーマ、テーブルに対してすべての権限を持つ。
- データ編集者: データの加工、修正が可能なユーザー。カタログ内のスキーマ、テーブルに対してRead/Writeの権限を持つ。
- データ閲覧者: データの閲覧が可能なユーザー。データオーナーに許可されており個人情報、秘匿情報も閲覧できる。カタログ内のスキーマ、テーブルに対してReadの権限を持つ。
- 一般ユーザー: データを閲覧するだけのユーザー。個人情報、秘匿情報は参照できない。

一般にユーザーはあるカタログにおいてはデータオーナー、別のカタログにおいては一般ユーザーとなるためログインユーザーごとに一意に決まらない。

## ログインページ
Active DirectoryやIdentity Providerを使ってシングルサインオンする。

## ヘッダ
- ログインユーザー名をアイコンとともに表示する
- 通知件数がわかる
    - データオーナーとして、閲覧申請通知、データ品質アラートが通知として表示される。
    - 一般ユーザーとして、データオーナーからの連絡事項やシステムアドミンの連絡事項が表示される。

## メニュー
- データカタログ
    - 作成申請: Unity Catalogにカタログを作成する。
    - 編集: 自身がデータオーナーとなっているカタログのMOUやチェックリストを編集できる。ユーザーリストから権限を編集、削除できる。
    - 閲覧申請: マーケットプレイスとしてデータカタログの一覧がDescriptionとともにカードで表示される。
        各データカタログのカードには申請、解除ボタンがついていて、
        申請を押すとデータオーナーが作成したMOUとチェックリストが表示され合意ボタンを押すことで合意を記録し閲覧権限を付与する。
        データオーナーの指示がない限り合意ボタンが押されたら自動的に閲覧権限を付与する。データオーナーの指示で閲覧申請の承認フェーズを設けることも可能。
        解除を押すと削除される。
        閲覧申請はデータオーナーに通知される。通知はポータル上とメールで行われる。解除は申請なく購読解除される。
    - 横断検索: 複数の時系列データのテーブルから検索文章に該当するカラムをメタデータのタグやDescriptionから探し出し時系列で結合して表示する。また、結果をCREATE VIEWする機能を持つ。

- データアプリ
    - 登録申請: アプリ名や使用しているカタログ、公開しているカタログを入力しマーケットプレイスに登録する。
    - 使用開始申請: マーケットプレイスとしてデータカタログの一覧がDescriptionとともにカードで表示される。
        登録、解除ボタンがついていて押すとアプリ管理者に通知される。
        データアプリはAWS上に構築されたDatabricks UnityCatalogを利用するサービス。
        サービス自体はこのデータ基盤で管理せず、連携先のAWSアカウントにリダイレクトする。
        連携先のAWS Cognitoを登録することで自動でユーザー登録することが可能。

- データ分析
    複数の時系列データを使ってデータ分析が可能。
    - 車両分析
        - 地域(日本、欧州、北米など)を選択
        - 時刻を選択
        - 地図を表示し指定した時刻での車両の位置情報を可視化する。
        - 車両を選択することでその時刻での車両状態が右のペインに表示される。
        - 解析に必要なカラムを選択して時系列のラインチャートにする。
        - 指定した車両の車載動画を再生できる
    - 統計分析
        - 地域(日本、欧州、北米など)を選択
        - 時刻の範囲を選択
        - 選択した時間で選択されたカラムに対する統計情報を表示する。
